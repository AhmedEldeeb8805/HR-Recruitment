# HR Recruitment

A Machine Learning project for analyzing HR recruitment data and predicting employee job-search behavior.

## Project Overview

This project explores an HR recruitment dataset, performs data analysis and visualization, prepares the data for machine learning, and builds a predictive model to identify candidates who may be looking for a new job opportunity.

The project focuses on understanding how factors such as education, relevant experience, experience level, and other candidate attributes relate to job-search behavior.

## Dataset

The project uses the `aug_train.csv` dataset.

The dataset contains candidate-related information that can be used to analyze recruitment patterns and train a machine learning classification model.

## Project Workflow

1. Load and inspect the dataset.
2. Perform data cleaning and preprocessing.
3. Explore the data using statistical analysis and visualizations.
4. Analyze relationships between candidate attributes and job-search behavior.
5. Prepare features for machine learning.
6. Train a classification model.
7. Evaluate the model using appropriate classification metrics.
